# Сборка Jimm под мост

`build.sh` собирает Jimm 0.6 для Motorola из исходников проекта с тем набором
модулей, который нужен мосту, и патчем по памяти. Ничего не ставит в систему:
JDK 8, Ant, ProGuard и заглушки MIDP скачиваются в рабочий каталог.

```sh
contrib/jimm/build.sh ~/jimm-build              # результат в ~/jimm-build/out/
contrib/jimm/build.sh ~/jimm-build "Jimm test"  # под другим именем — встанет рядом с обычным
```

Чем отличается от готовых сборок с jimm.org:

| | light | эта | full |
|---|---|---|---|
| модули | нет | `FILES`, `SMILES_STD`, `AVATARS` | `TRAFFIC,HISTORY,FILES,SMILES_STD,PROXY,ANTISPAM,AVATARS,PIM` |
| языки | RU | RU | семь |
| размер jar | ~261 КБ | ~196 КБ | ~274 КБ |
| «печатает» с телефона | только после прививки мостом | штатно | штатно |
| аватарки | нет | да | да |

`FILES` нужен не ради передачи файлов: под этим модулем в исходниках лежит
разбор способностей контактов, без которого Jimm не шлёт «печатает».
`PIM` — телефонная книга телефона (позвонить контакту), `HISTORY` — локальная
история (её заменяет `!last`), остальное мосту не нужно.

После сборки из jar убираются картинки, которые с мостом не нужны, а память
телефона занимают (каждая полоска 576×16 после распаковки — около 36 КБ в
куче): `xstatus.png` (X-статусы ICQ, сервер их не шлёт), `micons.png`
(значки главного меню), `clicons.png` (значки клиентов собеседников),
`logo.png` (заставка). Все их загрузки в Jimm обёрнуты в `try/catch`, а
`ImageList.elementAt` без картинки отдаёт `null`, так что клиент работает,
просто без значков. Это −20 КБ jar и около −125 КБ в куче.
`JIMM_KEEP_ICONS=1 build.sh …` оставляет картинки.

`flip-vibra.patch` — четвёртый режим вибрации в настройках «Оповещения →
Вибрация»: «Если скрыт (крышка закрыта)». Закрытую крышку Jimm напрямую не
видит, но с `FlipInsensitive: True` в манифесте телефон при закрытии не
усыпляет мидлет, а лишь убирает его экран — `Displayable.isShown()` даёт
`false`. В этом режиме вибрация идёт только когда экран Jimm не показан:
крышка закрыта или впереди другое приложение; с открытым Jimm — тишина.
Звук при этом играет по своей настройке, как и раньше.

Шрифт: в Jimm 0.6 шрифты системные (`Font.SIZE_SMALL/MEDIUM/LARGE`), мельче
системного «мелкого» не бывает; свой растровый шрифт появился только в 0.7.
Мелкий выбирается в настройках: «Интерфейс → Мелкий шрифт» (контакт-лист) и
«Сообщения → Мелкий шрифт» (чат, по умолчанию уже включён).

`chat-cap.patch` — ограничение на число открытых чатов в памяти. В Jimm каждое
входящее сообщение открывает чат, который живёт со всем текстом, пока его не
закроют руками; при сотне контактов и каналах это заполняет кучу телефона.
С патчем при открытии нового чата сверх двенадцати закрывается самый старый
из тех, что без непрочитанных и не на экране.

Преверификацию (StackMap для CLDC) делает ProGuard (`microedition="true"` в
`build.xml`), поэтому `preverify` из Sun WTK не нужен — вместо него заглушка
`preverify`, которая просто копирует классы. Классы компилируются под Java 1.1
(версия 45), как и штатно. ProGuard берётся версии 4.11 — с 6.2 сборка на
Motorola V3 падала при запуске («ошибка приложения»), хотя в эмуляторе
microemu работала; с 4.11 запускается.
